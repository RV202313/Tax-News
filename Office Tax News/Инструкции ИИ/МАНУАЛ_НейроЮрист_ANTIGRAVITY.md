## 2. Формат каждого запуска

**Вход:** команда владельца (выпуск готовится по запросу).

**Обязательный состав выпуска:** ровно 12 постов:
- 3 из Европы
- 3 из России
- 3 из США
- 3 из Казахстана

**Временное окно новостей:** последние 7 дней от даты запуска.

**Шаги:**
```
1. search_web() × 8–12 запросов (по 2–3 на каждый регион)
2. Собрать ≥ 20 кандидатов
3. Фильтровать по критериям ПРОТОКОЛ_НейроЮрист.md
4. Проверить каждого кандидата по РЕЕСТР_НОВОСТЕЙ_ИИ.md → исключить повторы
5. Отобрать 12 лучших (по 3 на регион)
6. Написать посты по шаблону PROCESS.md §2d
7. Записать посты в pipeline_ai/approved_ai/{дата}_{выпуск}.md
8. Отправить через send_ai_news.py или вручную через Telegram-клиент
9. Обновить РЕЕСТР_НОВОСТЕЙ_ИИ.md
10. Записать прогон в ЖУРНАЛ_ПРОГОНОВ_НейроЮрист.md
```

## 4. Критерии отбора

### Включать

| Критерий | Требование |
|---|---|
| Возраст | Не старше 7 дней |
| Конкретность | Есть цифры, сроки, инструменты, суммы или кейс |
| Источник | Первичный или авторитетный вторичный (со ссылкой на первичный) |
| Практическая ценность | Из текста понятно, что юрист может сделать уже сегодня |
| Регион | Входит в 4 обязательных (Россия, Казахстан, США, Европа) |

### Исключать безусловно

- Новость старше 7 дней
- Общие рассуждения без конкретного факта
- Пресс-релизы без подтверждённого кейса
- Повторы из `РЕЕСТР_НОВОСТЕЙ_ИИ.md`
- Любые новости по Украине
- Данные из HTML/JS-метаданных страниц

## 9. Сбои

- **Нет 12 уникальных новостей:** расширить запросы, не публиковать повторы. Зафиксировать в журнале.
- **Источник за пейволом:** пропустить, добрать другой.
- **Flood limit Telegram:** подождать `e.seconds + 2`, повторить.
- **Несовпадение аккаунта Telegram:** немедленно остановить всё.
- **Факт не верифицирован:** пометить `[ПРОВЕРИТЬ]`, не публиковать.
