# Руководство по запуску конвейера новостей в среде Antigravity (24/7)

Этот документ описывает, как перенести конвейер новостей «Новости Академии» на постоянный хост с агентом Antigravity, настроить расписание автозапуска и использовать портативные пути.

## 1. Структура проекта после распаковки

Все файлы конвейера, учетные данные и конфигурации теперь полностью автономны и находятся внутри одной папки:
```
Новости Академии/                # Папка с кодом конвейера и артефактами
  ├── .telegram_auth/            # Сессия Telethon, секреты (.env) и конфиг монитора
  │     ├── session.session      # Активная сессия Telethon
  │     ├── .env                 # API_ID и API_HASH для Telethon
  │     └── config.yaml          # Конфигурация монитора Telegram-каналов
  ├── News Claude/               # Автоматический конвейер (сбор, скоринг, дайджест)
  │     ├── config/
  │     │     └── sources.yaml   # Описания источников
  │     ├── scripts/
  │     │     ├── daily_run.py
  │     │     └── publish_batch.py
  │     └── ...
  ├── МАНУАЛ_ПОДГОТОВКИ_НОВОСТЕЙ_CODEX.md
  └── ...
```

## 2. Переменные окружения (опционально)

Для работы по умолчанию не требуются дополнительные настройки путей. Все скрипты автоматически настроены на чтение файлов сессии и `.env` из внутренней папки `.telegram_auth/`. 

Если вам всё же необходимо переопределить стандартные пути, используйте переменные окружения:
- `ACADEMY_SESSION_PATH` — абсолютный путь к файлу сессии `session.session` (по умолчанию `Новости Академии/.telegram_auth/session.session`).
- `ACADEMY_ENV_PATH` — абсолютный путь к файлу секретов `.env` с ключами `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` (по умолчанию `Новости Академии/.telegram_auth/.env`).

## 3. Настройка планировщика Antigravity (`schedule` cron)

Агент Antigravity на хосте 24/7 должен быть настроен на запуск следующих cron-задач (используя встроенный инструмент `schedule` или системный `cron` с аналогичными командами):

### 📅 Ежедневный сбор и подготовка дайджеста (Daily Run)
* **Время запуска**: 08:00 (Europe/Amsterdam) / 06:00 UTC
* **Инструкция (команда)**:
  ```bash
  cd "Новости Академии/News Claude"
  python3 scripts/daily_run.py --date $(date +%Y-%m-%d)
  ```
  *Скрипт соберет сырье из всех источников (Rechtspraak, ВС, Минфин, ФНС, Гарант, лиды Telegram) и сгенерирует черновик дайджеста в папке `pipeline/digest/`.*

### 🚀 Автоматическая отправка выпусков в Telegram-редчат (Editorial Delivery)
Поскольку посты требуют валидации и согласования, выпуски отправляются в редакционный чат за полчаса до дедлайна. Для каждого выпуска в approved-папке должен лежать файл `{дата}_release.json` (содержащий ровно 10 утвержденных позиций).

1. **Выпуск 09:00** (запуск в **08:30 CEST** / 06:30 UTC):
   ```bash
   cd "Новости Академии/News Claude"
   python3 scripts/publish_batch.py pipeline/approved/$(date +%Y-%m-%d)_release.json --execute-editorial
   ```
2. **Выпуск 13:00** (запуск в **12:30 CEST** / 10:30 UTC):
   ```bash
   cd "Новости Академии/News Claude"
   python3 scripts/publish_batch.py pipeline/approved/$(date +%Y-%m-%d)_release.json --execute-editorial
   ```
3. **Выпуск 17:00** (запуск в **16:30 CEST** / 14:30 UTC):
   ```bash
   cd "Новости Академии/News Claude"
   python3 scripts/publish_batch.py pipeline/approved/$(date +%Y-%m-%d)_release.json --execute-editorial
   ```

*Примечание: При успешном выполнении `publish_batch.py` автоматически обновит локальный каталог `ОПУБЛИКОВАННЫЕ_НОВОСТИ.md` и сохранит транзакционный sidecar в папке `pipeline/published/`.*

## 4. Восстановление и обслуживание сессии
* В случае возникновения ошибки `AuthKeyDuplicatedError` (если сессия была перехвачена параллельным клиентом), используйте скрипт `authorize_new_telethon_session.py` в интерактивном режиме для переавторизации и генерации нового файла `session.session`.
* Права на файл `session.session` должны быть строго ограничены (`chmod 600`), иначе `session_guard.py` заблокирует запуск из соображений безопасности.
