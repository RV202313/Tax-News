# Руководство по развертыванию и запуску комплекса «Office Tax News» на новом ПК

Данная инструкция содержит полный пошаговый регламент развертывания, настройки и запуска двух автоматизированных новостных конвейеров:
1. **«Новости Академии BEPS» (Налоговые новости / Codex / News Claude)** — международные и региональные налоговые новости (Pillar Two, DTA, DAC8, судебные прецеденты).
2. **«НейроЮрист»** — свежие новости ИИ в юридической сфере (по 3 новости на 4 региона: Россия, США, Европа, Казахстан).

---

## 1. Структура проекта и требования к системе

### 1.1 Системные требования
* **ОС:** Windows 10/11, macOS или Linux.
* **Python:** Версия **3.10** или выше.
* **Сеть:** Стабильный доступ к Telegram API и новостным источникам (без сетевых блокировок).
* **Среда Antigravity / Agent CLI:** Для работы автоматических кронов и ИИ-агента.

### 1.2 Обязательные библиотеки (Python Dependencies)
Все необходимые зависимости указаны в файле `requirements.txt`:
* `telethon` — взаимодействие с Telegram API для отправки постов и чтения комментариев.
* `Pillow` (PIL) — генерация и обработка обложек/карточек для новостей BEPS.
* `requests` / `urllib3` — сбор данных из новостных RSS-лент и web-источников.

---

## 2. Пошаговое развертывание на новом компьютере

### Шаг 1. Распаковка архива и создание окружения
1. Распакуйте архив `Office Tax News.zip` в рабочую директорию (например, `C:\Academy News\academy-news`).
2. Откройте терминал (PowerShell / Bash) в папке проекта и создайте изолированное виртуальное окружение Python:
   ```bash
   python -m venv .venv
   ```
3. Активируйте виртуальное окружение:
   * **Windows (PowerShell):** `.\.venv\Scripts\Activate.ps1`
   * **Linux/macOS:** `source .venv/bin/activate`
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Шаг 2. Настройка авторизации Telegram (Telethon)
Для отправки сообщений в каналы и чтения редакционного чата требуется авторизовать сессию Telegram:
1. Поместите действующий файл сессии в папку `.telegram_auth/session.session` или запустите скрипт авторизации нового аккаунта:
   ```bash
   python authorize_new_telethon_session.py
   ```
2. Введите ваш номер телефона и код подтверждения из Telegram.
3. Убедитесь, что сессия сохранилась по пути `.telegram_auth/session.session`.

### Шаг 3. Настройка правил Агента Antigravity (`GEMINI.md`)
Скопируйте файл правил из папки проекта в корневой каталог правил Агента:
* Путь в проекте: `.agents/rules/GEMINI.md`
* Этот файл отвечает за автоматический контроль будильников (планировщика) при каждом запуске сессии.

## 3. Автоматический контроль планировщика (Cron / Schedule)

При каждом запуске сессии Агента Antigravity вы обязаны проверить наличие 5 активных фоновых кронов. Если кроны отсутствуют, **перезапустите их с помощью инструмента `schedule`**:

1. **Утренний выпуск НейроЮрист (09:00 CEST / local time):**
   * `CronExpression`: `"0 9 * * *"`
   * `IsDaemon`: `true`
   * `Prompt`: `"Запуск утреннего выпуска новостей НейроЮрист (09:00 CEST). Согласно мануалу (Инструкции ИИ/МАНУАЛ_НейроЮрист_ANTIGRAVITY.md), собери 12 свежих новостей (по 3 на регион: Россия, Казахстан, США, Европа), напиши посты, отправь их в Telegram, обнови реестр и журнал прогонов."`

2. **Дневной выпуск НейроЮрист (13:00 CEST / local time):**
   * `CronExpression`: `"0 13 * * *"`
   * `IsDaemon`: `true`
   * `Prompt`: `"Запуск дневного выпуска новостей НейроЮрист (13:00 CEST)..."`

3. **Вечерний выпуск НейроЮрист (17:00 CEST / local time):**
   * `CronExpression`: `"0 17 * * *"`
   * `IsDaemon`: `true`
   * `Prompt`: `"Запуск вечернего выпуска новостей НейроЮрист (17:00 CEST)..."`

4. **Мониторинг редакционного чата:**
   * `CronExpression`: `"*/15 * * * 1-5"`
   * `IsDaemon`: `true`
   * `Prompt`: `"Check editorial Telegram chat for comments and instructions (runs collect_comments.py). Weekdays only (Mon–Fri)."`

5. **Редакционные выпуски BEPS (Новости Академии):**
   * `CronExpression`: `"0 6,10,14 * * 1-5"`
   * `IsDaemon`: `true`
   * `Prompt`: `"Run daily news release cycle for 08:00, 12:00, 16:00 CEST (triggers at 06:00, 10:00, 14:00 UTC, weekdays)."`

## 4. Регламент выполнения выпусков

### 4.1 Конвейер «Новости Академии BEPS» (Налоговые новости)
1. **Автосбор:** Запуск `python "News Claude/scripts/daily_run.py" --root "News Claude"` для сбора RSS/веб-источников, формирования шортлиста (`shortlist/*.json`) и дайджеста.
2. **Формирование одобренного файла:** Создание JSON файла в `News Claude/pipeline/approved/YYYY-MM-DD_HHMM_editorial.json` с 10 постами.
3. **Валидация (Dry-Run):** 
   ```bash
   python "News Claude/scripts/publish_batch.py" "News Claude/pipeline/approved/YYYY-MM-DD_HHMM_editorial.json" --root "News Claude"
   ```
4. **Публикация в Telegram:**
   ```bash
   python "News Claude/scripts/publish_batch.py" "News Claude/pipeline/approved/YYYY-MM-DD_HHMM_editorial.json" --root "News Claude" --execute-editorial
   ```
5. **Обновление логов:** Добавление строки прогона в `Инструкции Налоги/ЖУРНАЛ_ПРОГОНОВ_CODEX.md`.

### 4.2 Конвейер «НейроЮрист» (Новости ИИ в юридической сфере)
1. **Поиск новостей:** Поиск 12 свежих новостей за последние 7 дней (по 3 на регионы: Россия, США, Европа, Казахстан).
2. **Фильтрация:** Исключение повторов по `НейроЮрист_РЕЕСТР_НОВОСТЕЙ.md` и исключение любых упоминаний Украины.
3. **Лингвоконтроль:** 
   * Все латинские термины должны быть либо переведены на русский язык, либо записаны строго в ALL-CAPS (например: `AI ACT`, `GDPR`, `GOOGLE CLOUD`, `HARVEY`, `DGA`, `API`).
   * Для всех судебных дел обязателен дисклеймер: `Не является налоговой консультацией.`
4. **Запись и отправка:** Вставка постов в `POSTS` в файле `send_neuro_yurist_news.py` и запуск:
   ```bash
   python send_neuro_yurist_news.py
   ```
5. **Обновление логов:** Обновление `НейроЮрист_РЕЕСТР_НОВОСТЕЙ.md`, `ОПУБЛИКОВАННЫЕ_НОВОСТИ.md` и `ЖУРНАЛ_ПРОГОНОВ_НейроЮрист.md`.
