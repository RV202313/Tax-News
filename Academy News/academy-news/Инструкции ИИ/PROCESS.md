# Процесс «НейроЮрист» — конвейер новостей ИИ в юридической работе (v1)

Операционный runbook. Главный документ процесса.  
Принцип: Antigravity проводит веб-поиск по ключевым словам и источникам,
формирует дайджест кандидатов, проверяет на повторы по реестру, адаптирует
в пост-формат и отправляет в Telegram-чат НейроЮрист.  
Факты — только из первичных источников. Публикация без подтверждения — запрещена.

Редакционный принцип отбора: новость важна только если она содержит  
конкретный кейс, цифру, прецедент или инструмент — а не общую дискуссию.  
Ключевые регионы: Россия, Казахстан, США, Европа (ЕС, Германия, Нидерланды,  
Великобритания). Строгое исключение: Украина.

## 1. Схема конвейера

```
SEARCH → FILTER → DEDUPLICATE → DRAFT → SEND (Telegram) → LOG
```

## 2. Цикл подготовки выпуска (запуск по запросу владельца)

### a. SEARCH — поиск новостей

Antigravity выполняет поиск по ключевым словам из `config/topics_ai.yaml`  
и списку источников из `config/sources_ai.yaml`.

**Обязательные поисковые запросы на каждый выпуск:**

| Регион | Примеры запросов |
|---|---|
| Россия | «ИИ юридическая работа юрфирма кейс 2026», «ИИ суд доказательства РФ», «ИИ адвокат автоматизация», «закон об ИИ юристы» |
| Казахстан | «ИИ юридическая работа Казахстан 2026», «LegalTech Казахстан», «Цифровой кодекс юристы» |
| США | «AI legal work law firms USA 2026», «AI court hallucinations sanctions», «legal AI tool case study» |
| Европа | «AI legal work Europe Germany Netherlands 2026», «EU AI Act law firms compliance», «legaltech Europe implementation» |

**Приоритетные источники:**
- `artificialawyer.com` — ведущий мировой LegalTech-медиа
- `law.com` — американское юридическое издание
- `pravo.ru` — правовая база данных РФ
- `habr.com` — технические кейсы на русском языке
- `vc.ru` — российский бизнес-медиа
- `legartis.ai` — европейский LegalTech-аналитик
- `rsgi.co` — независимые исследования LegalTech
- `americanbar.org` — Американская адвокатская ассоциация
- `gov.kz` — официальные новости Казахстана
- `zakon.kz` — правовая база Казахстана

### b. FILTER — фильтрация

Отсеивать безусловно:
1. Новости старше **7 дней** от даты выпуска
2. Материалы без конкретики: нет цифр, кейсов, инструментов, прецедентов
3. Внутренние анонсы конкретных блогеров/курсов без реального кейса
4. Пресс-релизы стартапов без рабочего подтверждённого кейса
5. Абстрактные рассуждения «заменит ли ИИ юриста»
6. Любые материалы по Украине

Оставлять только:
1. Конкретные кейсы компаний/юрфирм с цифрами (время, деньги, объём)
2. Законодательные акты и регуляторные решения с датой и номером документа
3. Судебные прецеденты с номером дела и датой
4. Сравнения и разборы конкретных инструментов с примерами применения
5. Пошаговые воркфлоу для практикующих юристов

### c. DEDUPLICATE — проверка повторов

Перед включением каждого кандидата проверить по `РЕЕСТР_НОВОСТЕЙ_ИИ.md`:
- URL первичного источника
- Тема + регион + период
- Нормализованный заголовок (нечёткое совпадение ≥ 0.85)

Материал, уже попавший в реестр, не включать ни при каких условиях.

### d. DRAFT — подготовка постов

**Обязательная структура каждого поста:**

```
[Флаг страны] [Страна]: [Заголовок — конкретная суть или польза]

[1–2 предложения: что произошло, кто участник, когда]

📌 **Что сделано / Как работает:**
• Пункт 1 — конкретное действие или инструмент
• Пункт 2 — показатели: время, деньги, количество
• Пункт 3 — результат для практики

💡 **Практический вывод / Как применить у себя:**
[Конкретный совет: какой промпт, сервис, логика, настройка]

🔗 Источник: [ссылка]

#хештег1 #хештег2 #НейроЮрист #АкадемияBEPS #АкадемияБЕПС
```

**Обязательные постоянные хештеги в каждом посте:**  
`#НейроЮрист #АкадемияBEPS #АкадемияБЕПС`

**Тематические хештеги** выбираются из `config/hashtags_ai.yaml`.

**Языковое правило:**  
Весь текст — на естественном русском языке.  
Английские слова с русским эквивалентом — переводить.  
Оставлять только: `ИИ`, `LegalTech`, `AI Act`, `GDPR`, `RAG`, `LLM`,  
аббревиатуры без точного русского аналога.

### e. SEND — отправка в Telegram

**Целевой чат:** `https://t.me/+l_1s3JcOKLI4OGI0` (НейроЮрист)  
**Сессия:** `.telegram_auth/academy_news_new.session`  
**Скрипт отправки:** `scripts/send_ai_news.py`

Порядок отправки:
1. Запустить `scripts/send_ai_news.py --posts pipeline/approved_ai/{дата}_{выпуск}.json`
2. После успешной отправки каждого поста — обновить `РЕЕСТР_НОВОСТЕЙ_ИИ.md`
3. Выдержать паузу 3 секунды между постами (защита от flood limit)

### f. LOG — журналирование

После каждого выпуска добавить запись в `ЖУРНАЛ_ПРОГОНОВ_НейроЮрист.md`:
- дата и время выпуска
- сколько кандидатов найдено / сколько отфильтровано / сколько опубликовано
- повторы: сколько исключено и почему
- ошибки отправки (если были)
- обновление реестра: статус

## 3. График выпусков

**ЕЖЕДНЕВНО, три выпуска:**

| Дедлайн | Старт подготовки | Действие |
|---|---|---|
| **09:00 CEST** | 08:00 | Поиск → фильтр → реестр → 12 постов → отправить |
| **13:00 CEST** | 12:00 | Поиск → фильтр → реестр → 12 постов → отправить |
| **17:00 CEST** | 16:00 | Поиск → фильтр → реестр → 12 постов → отправить |

Каждый выпуск: **3 Европа + 3 Россия + 3 США + 3 Казахстан = 12 постов**.  
В рамках одного дня выпуски не должны повторять друг друга — реестр проверяется перед **каждым** выпуском, включая посты этого же дня.  
Пропуск выпуска без уведомления владельца = критический сбой.


## 4. Приём указаний из чата

1. Любое сообщение в чате НейроЮрист, не являющееся публикуемым постом, воспринимается как **редакционное указание**.
2. Понятное указание — зафиксировать в `ПРОТОКОЛ_НейроЮрист.md` и применить к следующему выпуску.
3. Если указание противоречит предыдущему — уточнить у владельца, не применять молча.
4. Отчёт о принятых изменениях — публиковать в этом диалоге Antigravity, не в Telegram-чате.

## 5. Дедупликация и реестр

- **Реестр:** `РЕЕСТР_НОВОСТЕЙ_ИИ.md` — единственный источник правды о том, что уже опубликовано.
- Реестр проверяется **перед каждым выпуском**.
- Совпадение по URL или теме+регион+период = повтор, блокировать.
- Новая стадия прежнего события допустима только при появлении нового факта (цифра, решение, дата); связь с предыдущим постом указывается явно.

## 6. Правила отказа

- Нет 12 уникальных новостей за неделю → **повторить поиск с расширенными запросами**, не публиковать повторы.
- Не удаётся проверить первичный источник → материал не включать, пометить `[ПРОВЕРИТЬ]`.
- Flood limit Telegram → выдержать паузу `e.seconds + 2` и повторить.
- Источник на странице за пейволом → пропустить или добрать через Chrome.
